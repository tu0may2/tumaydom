# Установка на Windows с нуля

Всё делается в **PowerShell** — это чёрное окно для команд. Открыть: кнопка
«Пуск» → набрать `powershell` → запустить «Windows PowerShell».

Команды копируются целиком и вставляются правым щелчком мыши, затем Enter.

---

## Шаг 1. Python

1. Открыть https://www.python.org/downloads/ и нажать «Download Python».
2. Запустить скачанный файл.
3. **Внизу окна установщика поставить галочку «Add python.exe to PATH»** — без неё
   ничего не заработает.
4. Нажать «Install Now», дождаться конца, закрыть.

Проверка — в PowerShell:

```powershell
py --version
```

Должно ответить `Python 3.12...` или похоже. Если пишет, что команда не найдена —
переустановить с галочкой из пункта 3.

## Шаг 2. Ollama — модель, которая будет думать

1. Открыть https://ollama.com/download и скачать версию для Windows.
2. Установить и запустить. В трее (у часов) появится значок ламы — значит работает.
3. Скачать модель. В PowerShell:

```powershell
ollama pull gemma3:12b
```

Это 8 ГБ, займёт время. Модель требует около 12 ГБ оперативной памяти.
Если у компьютера 8 ГБ или меньше — вместо неё:

```powershell
ollama pull gemma3:4b
```

4. Увеличить контекст, иначе бот будет «забывать» историю тренировок:

```powershell
setx OLLAMA_CONTEXT_LENGTH 16384
```

После этого **выйти из Ollama** (правый щелчок по значку в трее → Quit) и
запустить её заново из меню «Пуск».

## Шаг 3. Скачать проект

1. Открыть страницу репозитория на GitHub.
2. Переключить ветку на `claude/ai-workout-analysis-agent-kpnsle`
   (кнопка с названием ветки слева над списком файлов).
3. Зелёная кнопка **Code** → **Download ZIP**.
4. Распаковать архив в простую папку без русских букв и пробелов, например
   `C:\fitcoach`.

## Шаг 4. Установить зависимости

В PowerShell перейти в папку проекта и создать окружение:

```powershell
cd C:\fitcoach
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

Последняя команда качает библиотеки, это пара минут.

## Шаг 5. Файл с настройками

```powershell
Copy-Item .env.example .env
notepad .env
```

Откроется Блокнот. Найти строку `TELEGRAM_BOT_TOKEN=` и вписать после знака `=`
свой токен от BotFather. Сохранить (Ctrl+S) и закрыть.

Если брал модель `gemma3:4b`, добавить туда же строку:

```
FITCOACH_MODEL=gemma3:4b
```

> Блокнот любит дописывать `.txt` к имени файла. Если после сохранения появился
> `.env.txt` — переименовать обратно в `.env`.

## Шаг 6. Проверка

```powershell
.\.venv\Scripts\python.exe -m fitcoach.doctor
```

Команда по очереди проверит: отвечает ли Ollama, скачана ли модель, работает ли
разбор JSON, принимаются ли картинки, на месте ли токен Telegram. Напротив
каждого пункта будет `[ ok ]` или `[fail]` с подсказкой, что чинить.

## Шаг 7. Запуск

```powershell
.\.venv\Scripts\python.exe main.py
```

Окно PowerShell должно **оставаться открытым** — пока оно открыто, бот работает.
Свернуть можно, закрыть нельзя.

Теперь в Telegram найти своего бота по имени, нажать «Начать» и написать `/start`.

Дальше:

1. Отправить `/whoami` — бот вернёт числовой `chat_id`.
2. Открыть `.env` (`notepad .env`), вписать его в строку `TELEGRAM_OWNER_CHAT_ID=`
   и убрать `#` в начале этой строки, если он есть.
3. Перезапустить бота: в PowerShell нажать Ctrl+C, затем снова запустить команду
   из шага 7.

Это нужно только для утренней рассылки — на команды бот отвечает и без неё.

## Что писать боту

- О себе: возраст, рост, вес, цель, сколько дней в неделю тренируешься,
  какой инвентарь, какие ограничения по здоровью.
- Тренировки: «жим 80x5x5 RPE 8» или «бег 10 км за 52:30, пульс 148».
- Скриншоты из Garmin Connect со статистикой сна.
- `/export` — выгрузка всей статистики в Excel.

## Если что-то пошло не так

| Симптом | Что делать |
|---|---|
| `py` не найдена | Переустановить Python с галочкой «Add python.exe to PATH» |
| Доктор пишет, что Ollama не отвечает | Запустить Ollama из «Пуск», проверить значок ламы в трее |
| Доктор пишет, что модель не скачана | Выполнить `ollama pull gemma3:12b` |
| Бот молчит в Telegram | Проверить, что окно PowerShell с `main.py` открыто и без ошибок |
| Ответы идут по минуте | Нормально для модели на процессоре. Быстрее — `gemma3:4b` или облачный провайдер |
| Скриншоты не разбираются | Модель без поддержки картинок — нужна `gemma3`, а не `qwen2.5`/`llama3.1` |

Бот работает, только пока включён компьютер и открыто окно PowerShell.
Чтобы он был доступен круглосуточно, нужен арендованный сервер — это отдельная
настройка, см. `deploy/` в корне проекта.
