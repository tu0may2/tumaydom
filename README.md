# FitCoach — ИИ-агент по тренировкам, сну и питанию

Телеграм-агент, который ведёт дневник силовых и кардио тренировок, разбирает
показатели сна и восстановления (выкладки Garmin Connect / Connect Go), считает
питание, каждое утро присылает план на день и раз в неделю пересобирает стратегию.

Модель — любая: по умолчанию **бесплатный Google Gemini**, но так же работают
Groq, OpenRouter, Mistral, локальная Ollama и Claude. Хранилище — SQLite.
Расписание — JobQueue внутри бота, отдельный cron не нужен.

## Что умеет

**Приём данных**
- Свободный текст: «жим 80x5x5 RPE 8, потом тяга 3х8 по 120» или «бег 10 км за 52:30, пульс 148».
- Скриншоты выкладок из Garmin Connect / Connect Go — читаются vision-моделью
  (сон, фазы, HRV, пульс покоя, body battery, стресс, SpO2).
- Файлы выгрузок: CSV активностей и JSON сна разбираются кодом без обращения к
  модели; незнакомые форматы уходят на разбор в LLM.
- Замеры: вес, талия, калории, белок, шаги — сохраняются как метрики с датой.

**Аналитика**
- Разбор каждой присланной тренировки в сравнении с прошлыми такими же сессиями.
- Тоннаж, километраж, средний RPE по неделям; тренд сна против среднего за 7 дней;
  динамика веса и других замеров. Все цифры считаются кодом, модель только
  интерпретирует.
- Недельный разбор + новый план на следующую неделю (дни, блоки, целевое RPE,
  калории и БЖУ), сохраняется в базу.

**Проактивность**
- Утренний дайджест: состояние по сну → тренировка на сегодня → восстановление →
  питание на день → что прислать вечером.
- Недельный разбор по расписанию (по умолчанию воскресенье 19:00).

**Выгрузка в Excel** (`/export`) — книга с листами:
- *Обзор* — итоги за период и автоматические сигналы (скачок объёма, недосып,
  падение HRV, рост пульса покоя, средний RPE у отказа).
- *Разбор* — текст от модели: что работает, что тормозит, что менять.
- *Недели* — объём, RPE, сон, HRV, пульс покоя и вес в одной таблице по неделям,
  с графиками; видно, какая нагрузка чем оплачена.
- *Прогресс* — по каждому упражнению оценка 1ПМ (формула Эпли), лучший подход и
  изменение в кг и процентах.
- *Тренировки*, *Сон*, *Замеры* — сырые данные с фильтрами.

## Команды бота

| Команда | Что делает |
|---|---|
| `/start`, `/help` | Регистрация и справка |
| `/today` | Сессия из плана на сегодня |
| `/plan` | План на неделю целиком |
| `/digest` | Утренний разбор прямо сейчас |
| `/week` | Недельный разбор и новый план |
| `/export` | Выгрузка всей статистики в Excel |
| `/profile` | Профиль: цель, антропометрия, ограничения |
| `/whoami` | `chat_id` — нужен для `TELEGRAM_OWNER_CHAT_ID` |

Всё остальное — обычные сообщения, фото и файлы.

## Запуск

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env      # вписать TELEGRAM_BOT_TOKEN и ключ провайдера
python main.py
```

Токен бота берётся у @BotFather. Про ключ модели — раздел ниже.
После первого `/start` профиль создаётся автоматически; напиши боту о себе
(возраст, рост, вес, цель, сколько дней в неделю тренируешься, инвентарь,
ограничения) — это попадёт в профиль и будет учитываться во всех разборах.

## Где взять бесплатный ключ

| Провайдер | Где ключ | Бесплатно | Читает скриншоты |
|---|---|---|---|
| `gemini` (по умолчанию) | aistudio.google.com/apikey | да, бессрочный free tier | да |
| `groq` | console.groq.com/keys | да, с лимитом запросов | нет |
| `openrouter` | openrouter.ai/keys | модели с суффиксом `:free` | у части моделей |
| `mistral` | console.mistral.ai | пробный тариф | да |
| `ollama` | ключ не нужен | полностью локально | зависит от модели |
| `anthropic` | console.anthropic.com | нет, по предоплате | да |

Рекомендация — **Gemini**: ключ выдаётся сразу по Google-аккаунту, без карты, и
это единственный из бесплатных, кто уверенно читает скриншоты выкладок Garmin.

```
FITCOACH_PROVIDER=gemini
GEMINI_API_KEY=AIza...
```

Провайдер без vision (например Groq) на скриншот честно ответит, что не умеет
читать картинки, — данные придётся пересказать текстом; всё остальное работает.

Любой свой или локальный сервер с протоколом OpenAI подключается так:

```
FITCOACH_PROVIDER=openai
FITCOACH_BASE_URL=http://localhost:11434/v1
FITCOACH_MODEL=llama3.1
```

### На сервере

```bash
sudo cp deploy/fitcoach.service /etc/systemd/system/
sudo systemctl enable --now fitcoach
```

## Конфигурация

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | — | токен бота |
| `TELEGRAM_OWNER_CHAT_ID` | — | чат для рассылок |
| `FITCOACH_PROVIDER` | `gemini` | провайдер модели |
| `FITCOACH_API_KEY` | — | ключ; можно вместо него `GEMINI_API_KEY` и т.п. |
| `FITCOACH_MODEL` | по провайдеру | переопределить модель |
| `FITCOACH_BASE_URL` | по провайдеру | свой или локальный эндпоинт |
| `FITCOACH_DB_PATH` | `data/fitcoach.db` | файл базы |
| `FITCOACH_TIMEZONE` | `Europe/Moscow` | часовой пояс расписания |
| `FITCOACH_MORNING_TIME` | `07:30` | время утреннего дайджеста |
| `FITCOACH_WEEKLY_DAY` / `_TIME` | `sun` / `19:00` | когда недельный разбор |

## Структура

```
fitcoach/
  config.py          настройки из окружения
  db.py              SQLite: тренировки, сон, метрики, профиль, план
  providers.py       Anthropic и любой OpenAI-совместимый эндпоинт
  llm.py             фасад: текст и JSON по схеме, с картинками или без
  schemas.py         JSON-схемы структурированных ответов
  prompts/           промпты: разбор входа, тренер, утро, неделя, анализ
  ingest/parser.py   разбор текста и скриншотов через модель
  ingest/files.py    CSV/JSON выгрузки без модели
  analysis/stats.py  агрегаты: недели, тренд сна, динамика замеров
  analysis/progress.py  1ПМ по упражнениям, связки нагрузка↔сон↔результат
  analysis/coach.py  сценарии: разбор, дайджест, недельная стратегия
  export.py          выгрузка статистики в Excel
  bot.py             хендлеры Telegram
  scheduler.py       ежедневные и недельные джобы
main.py              точка входа
deploy/              unit-файл systemd
```

## Тесты

```bash
python -m pytest
```

Покрыты детерминированные части: хранилище, парсер выгрузок Garmin, агрегаты,
прогресс по упражнениям и эвристики-флаги, сборка Excel, выбор провайдера и
разбор «грязного» JSON от моделей послабее. Вызовы модели в тестах не выполняются.

## Ограничения

- `.fit` не разбирается — нужен экспорт в CSV/JSON или скриншот.
- Автосинхронизации с Garmin нет: данные приходят сообщениями и файлами.
  Официальный Garmin API требует партнёрского доступа, а неофициальный
  `garminconnect` ходит по логину и паролю и ломается при сменах API — если
  такой вариант нужен, это отдельный модуль поверх `ingest/`.
- Бот не заменяет врача: при боли, признаках травмы или резких изменениях
  самочувствия он рекомендует обратиться к специалисту.
- Качество разборов зависит от модели: бесплатные модели заметно слабее в
  недельной стратегии, чем Claude или Gemini Pro. Структурный разбор входящих
  сообщений и все цифры от модели не зависят — они считаются кодом.
- Оценка 1ПМ по Эпли — приблизительная и врёт на подходах больше ~10 повторов.
