# Мурлыка — виртуальный кот

Игра про кота в духе «Говорящего Тома»: один HTML-файл, который открывается
двойным кликом и работает без интернета, сервера и установки.

Кот нарисован кодом: силуэт из сплайнов, поверх — десятки тысяч коротких
штрихов шерсти, светотень на стыках, бархатный пух по контуру. Никаких
картинок в комплекте, поэтому файл весит около 100 КБ.

## Что умеет

**Свой кот.** Десять окрасов (рыжий, табби, смокинг, сиамский, трёхцветная,
голубой и другие — с полосками, пятнами и затемнением морды), шесть вариантов
глаз, включая разные, и имя. Меняется в любой момент бесплатно.

**Уход.** Сытость, бодрость, радость и чистота падают со временем — и пока
игра закрыта тоже. Шесть видов еды с разным эффектом, мытьё, сон. Голодный и
грязный кот теряет настроение быстрее.

**Реакции на прикосновения.** Погладить голову или живот — щурится, мурлычет,
летят сердечки. Ткнуть в нос — чихает и отшатывается. Тронуть ухо — дёргает им.
Потянуть за хвост — обижается и теряет очко радости. Разбудить спящего — тоже
не оценит. Кот следит взглядом за курсором и наклоняет голову.

**Мини-игры за монеты.** «Поймай мышку» на реакцию, «Лови клубки» на три жизни
с растущей скоростью, «Найди пару» на память. Монеты тратятся в магазине.

**Магазин.** Ошейник, бантик, шапочка, очки, шарф и корона — надеваются на кота
и рисуются поверх шерсти. Четыре комнаты: гостиная, у окна, сад и ночь
с луной и гирляндой.

**Звук.** Синтезируется на лету: мурчание, мяуканье, хруст корма, плеск воды,
монеты. Отключается кнопкой в шапке.

## Как запустить

Самый простой способ: скачать `index.html` и открыть двойным кликом — и всё.

### Выложить в интернет

Файл статический, подойдёт любой хостинг:

- **GitHub Pages** — положить `index.html` в ветку, включить Pages в настройках
  репозитория, игра будет по адресу `https://<логин>.github.io/<репозиторий>/`.
- **Netlify / Vercel** — перетащить файл в окно загрузки.
- **Свой сервер** — положить в корень сайта рядом с остальными файлами.

### Локальный сервер (если нужен)

Для простого открытия файла сервер не требуется, но если хочется:

```bash
python -m http.server 8000
# дальше http://localhost:8000
```

## Сохранение

Прогресс хранится в `localStorage` браузера, в котором играли. Это значит:

- на другом устройстве или в другом браузере будет новый котёнок;
- в режиме инкогнито прогресс не сохранится;
- очистка данных сайта удалит кота.

Такова плата за автономность: без сервера сохранять больше некуда.

## Как устроено

Весь код в `index.html`, разбит на блоки:

| Блок | Что делает |
|---|---|
| Справочники | окрасы, глаза, еда, аксессуары, комнаты |
| Состояние | показатели, расчёт падения за прошедшее время, сохранение |
| Звук | синтез через WebAudio, без файлов |
| Шерсть | штрихи, краевой пух, светотень, рисунок окраса |
| Геометрия | силуэты тела, головы, ушей, лап, хвоста; сборка кэш-слоёв |
| Морда | глаза с радужкой и вертикальным зрачком, нос, усы, веки |
| Комнаты | четыре фона, рисуются процедурно |
| Анимация | дыхание, моргание, хвост, наклон головы, прикосновения |
| Интерфейс | показатели, магазин, внешность, мини-игры |

Тяжёлые слои (тело, голова, хвост) рисуются один раз в offscreen-канвы и
переиспользуются каждый кадр — поэтому на телефоне не греется.

## Ограничения

- Кот нарисован вектором с процедурной шерстью. Это не фотореализм: без
  готовых 3D-моделей в браузере его не получить, зато файл автономный и
  открывается мгновенно.
- Голос не записывается и не повторяется — для этого нужен доступ к микрофону,
  который в локальном файле работает не везде.
